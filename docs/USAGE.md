# レシート家計簿 — Windows版

現在のバージョン: **1.4.2**。タイトルバーと **設定 → アプリ情報** でも確認できます。

レシート画像をLAN内のLM Studioで読み取り、確認後に手元のExcel家計簿へ保存するアプリです。画像はLM Studioサーバーへ送信されます。Excelファイルはアプリを使うWindows PCに保存されます。

## 使い始める

1. 推論用PCのLM Studioで、画像入力に対応したローカルモデルをダウンロードして読み込みます。モデル選択時はクラウド版ではなくローカル版を選んでください。
2. LM StudioのDeveloper画面でサーバーを開始し、**Serve on Local Network** と **Require Authentication** を有効にします。トークンを1つ作成してください。サーバーのポートは既定なら `1234` です。
3. Windowsファイアウォールでは、家計簿アプリを使うPCからサーバーのポートへの接続を許可します。ルーターのポート開放は不要です。
4. `ReceiptLedger.exe` を起動し、**設定**にサーバーのLAN内アドレス（例: `http://192.168.1.10:1234/v1`）とトークンを入力します。**接続テスト・モデル取得**でモデルを選び、設定を保存します。
5. **レシート登録**で画像を選ぶか、アプリ画面へ画像をドラッグ＆ドロップして追加し、**選択中を読み取る**を押します。読み取った日付・店舗・合計額・商品名・数量・単価・金額・詳細・補足を元画像と見比べて修正し、**この1件を記録**を押します。商品金額が空欄なら数量×単価から計算します。

新規利用時の家計簿は、**実行ファイル横の `data\excel\レシート家計簿.xlsx`** に作成します。記録済み画像の初期保存先は **`data\images`** です。既存の設定がある場合は以前のExcel・画像保存先を引き継ぎます。Excelがなくてもアプリは `.xlsx` を保存できます。

## LM Studio接続設定の保存

「接続テスト・モデル取得」が成功すると、URL・認証情報・取得したモデル一覧・選択モデルを自動保存します。その後のモデルの選択も保存します。モデル名を手入力した場合はEnterまたは別の欄へ移動すると確定します。次回起動時は前回の状態が表示されます。

モデル取得を行わずに画像を読み取った場合も、最初の成功時に使用した接続設定を保存します。接続に失敗した設定は、前回保存した接続情報を自動で置き換えません。「設定を保存」を押した場合は、従来どおり入力した設定を明示的に保存できます。

認証トークンはWindows資格情報マネージャーに保存します。設定JSON・データバックアップにはトークンを含めません。LM Studioへの自動接続・モデル自動ロードは行いません。

## 保存先・保存済み画像の表示復旧

- **設定 → 家計簿ファイル／画像の保存先 → 設定を保存** で変更できます。保存先フォルダに書き込めるか確認してから設定を保存します。書き込めない場所にアプリを置いた場合は、ドキュメントなど書き込み可能な場所を指定してください。
- **元画像をアプリ専用フォルダに保存する** がオンの場合、Excelに記録する際に画像を指定フォルダへコピーします。画像一覧への追加だけではコピーしません。
- 画像保存先の変更は今後の記録から適用します。既存画像を自動移動・削除することはなく、以前の保存先も参照できます。既存データをまとめて別の場所へ移す場合は、一括バックアップから新しい場所へ復元できます。
- 取り込み元の画像が移動・削除された場合や表示できない場合は、保存済みコピーから表示します。保存済みコピーがある場合は再読み取りにも利用できます。コピーも存在しない場合は、文字情報だけを保持して画像が見つからない旨を表示します。
- 旧版の一覧も、対応するExcel記録を一意に照合できれば保存済み画像を表示できます。
- 新たに保存するExcelの画像参照は、同じドライブではExcelからの相対位置で保存します。アプリ配下の設定・下書きのパスもアプリからの相対位置で保持するため、`data` を一緒にコピーすれば移動後も参照できます。別ドライブ・旧版の絶対パスはそのまま保持します。
- 設定・下書き・削除履歴は引き続き `%LOCALAPPDATA%\ReceiptLedger` に保存します。別PCへの移行には下記の一括バックアップを使います。

## データ一式のバックアップ・復元

1. **設定 → データ一式をバックアップ** を押し、ZIPの保存場所を選びます。
2. 現在のExcel、一覧・削除履歴から参照している家計簿、その通常／削除前／復元前バックアップ、画像保存先の画像、下書き・削除履歴で参照する画像、設定をまとめます。存在しないファイルは完了画面で知らせます。アプリから参照していない別の家計簿や、別フォルダに出力した過去の一括ZIPは対象外です。
3. 復元時は **データ一式を復元** でZIPと復元先フォルダを指定します。現在のデータを `%LOCALAPPDATA%\ReceiptLedger\backups` に退避した後、指定先に `ReceiptLedger-restored-日時` を新規作成します。
4. ファイルの整合性を検証し、Excelの画像参照・下書きのパスを復元先に合わせて更新してから、設定と下書きを切り替えます。元のExcel・画像は上書きしません。

認証トークンはZIPに含めず、復元しても変更しません。別PCではLM Studioの認証トークンを再設定してください。復元途中で終了した場合は、次回起動時に保存済みの切り替え情報から再開します。形式不正・検証失敗時は切り替えません。現在の一括復元は展開後20GBまで対応します。

## 容量表示・バックアップの世代管理

- **設定 → 容量を確認** で、現在のExcel、画像保存先と参照中の保存済み画像、この家計簿の通常バックアップ・削除前／復元前の退避、標準フォルダ内の一括ZIP、設定・下書きの件数と容量を表示します。
- **通常バックアップの保持数** は初期値20世代、1〜999世代で設定できます。Excel保存のたびに同じフォルダへ日時付きバックアップを作成し、古い通常バックアップを整理します。
- **古い通常バックアップを整理** では、画面に指定した世代数を残すために削除する件数を確認してから整理できます。設定を保存すると、その保持数を次回以降のExcel保存でも使います。
- 自動整理の対象は、この家計簿の `.backup-日時.xlsx` だけです。削除前・復元前の退避、一括ZIP、他の家計簿のバックアップは削除しません。
- バックアップ整理に失敗しても、成功したExcel保存を失敗扱いにせず、整理できなかった旨を表示します。

## アプリの更新

**設定 → アプリ情報 → 更新手順を見る**、または同梱の `UPDATE.md` を参照してください。更新前にデータ一式をバックアップし、新版は新しいフォルダへ展開します。アプリ横の `data` を使っている場合は新版の実行ファイル横へコピーしてください。`ReceiptLedger.exe` と `_internal` は同じ版の組み合わせで使用します。

## 画面の見やすさ・ダークモード

- 画面右上または **設定 → 画面表示** で **Windowsに合わせる／ライト／ダーク** を選べます。初期設定は **Windowsに合わせる** です。Windowsの「既定のアプリモード」を参照し、起動中の変更も約2秒で反映します。
- **ライト／ダーク** を選ぶと手動設定が優先されます。選択は自動保存され、次回起動時にも引き継ぎます。以前の版で保存したライト／ダーク設定も保持するため、自動に戻す場合は **Windowsに合わせる** を選んでください。
- 読み取り処理中も画面右上から切り替えられます。入力内容とレシートのチェック・確認済み状態は保持します。
- 画像一覧のチェック欄は大きな枠で表示します。選択すると緑色の背景と太いチェックが付きます。読み取り前など選択できない行には横線を表示します。行を選んでスペースキーでもチェックを切り替えられます。
- 表示モードの変更はアプリ画面に適用されます。Excelのテンプレートは従来の書式で保存します。

## レシートを一括で読み込む

1. **画像を追加**で複数の画像を選ぶか、複数画像を画面へドラッグ＆ドロップします。JPEG、PNG、WebP、HEIC、HEIFを混在させられます。
2. **未読を一括読み込み**を押すと、一覧の未読画像を設定した同時解析数でLM Studioに読み取らせます。進捗と画像ごとの状態を表示します。処理中に追加した画像は次回の一括読み込み対象です。
3. 一覧の画像を選び、元画像と読み取り結果を確認・修正します。**ほかの画像を読み取り中でも、読み取り済みのレシート情報は編集できます。** 画像を切り替えても修正内容は保持されます。右側の欄が収まらない場合はスクロールできます。
4. 内容を確認したレシートの左側にチェックを付けます。チェックだけではExcelに保存されません。
5. 読み取り終了後、画面下部の **未記録○件をExcelに記録** を押します。件数・税込合計・消費税額・記録先と、重複候補や金額差を確認し、「はい」で保存します。チェックした分だけを、レシートごとに別々の記録として同じ家計簿に追記します。

日付や金額などに不備があれば保存前に修正箇所を表示します。修正するか、そのレシートのチェックを外して再度押してください。キャンセルや保存失敗時は入力とチェックを保持します。保存に成功すると **記録済み** になり、チェックが外れます。

1枚だけ保存する場合は **この1件を記録** を使います。一括記録ではチェックを付けた画像だけが対象です。

読み取り処理中でも完了済みの画像を編集・チェックできます。現在読み取っている画像と、処理待ちの画像は結果による上書きを防ぐため編集できません。Excelへの登録は一括読み込みの終了後に行います。

- **失敗分を再試行**: 失敗した画像だけを再度読み取ります。ほかの画像の読み取り結果・修正内容は保持します。
- **停止**: 新しい画像の送信を止め、送信済みの画像（最大2件）がすべて終了したら停止します。通信の応答待ちは1回につき最大約4分です。応答形式の自動再試行が入るとさらに待つ場合があります。完了済みの結果は保持され、**未読を一括読み込み**で未処理分を再開できます。
- 読み取り済み・確認済み・記録済みの画像は未読の一括処理から除外します。読み直す場合はその画像を選び、**選択中を読み取る**を押します。
- Excel保存に失敗した場合は読み取り結果とチェックを保持します。原因を解消して、もう一度まとめて記録できます。記録済みの画像は次の一括記録から除外します。
- 下書きは自動保存され、再起動後に復元します。家計簿への確定には記録ボタンを使ってください。

## 下書きの自動保存・復元

- 入力・修正した内容、商品明細、取り込んだ画像一覧、チェック状態、記録先、編集中の支出、選択中の画像の表示倍率・回転を約1秒ごとに保存します。読み取り完了時と通常終了時にも保存します。
- 次回起動時に自動復元します。読み取り中に中断した画像は未読として再開でき、完了済みの結果は保持します。再起動だけで画像の再送信は行いません。
- 読み取り中に終了操作をすると、下書きを保存して停止を予約し、送信済みの画像の処理がすべて終わってから終了します。強制終了や停電では最後の保存後の入力が失われる場合があります。
- 保存状況は画面下部に表示します。下書きはこのPCの `%LOCALAPPDATA%\ReceiptLedger\draft-session.json` に保存されます。Excelへの記録とは別です。複数のアプリ起動による下書きの上書きを防ぐため、通常起動は1つに制限します。
- 元画像の場所と記録時の保存済みコピーを記憶します。元画像を移動・削除した場合は保存済みコピーで表示を復旧します。両方ない場合でも入力内容は確認・記録できます。
- 下書きを破棄してやり直す場合は **設定 → 下書きと画像一覧を消去** を使います。Excelの記録と元画像は残ります。

## 画像の確認と画面配置

- 画像上部の **＋／−** または **Ctrl＋マウスホイール** で拡大・縮小します。拡大後は画像をドラッグして移動できます。
- **全体表示** は画像全体を表示領域に合わせ、**100%** はプレビューを等倍で表示します。
- **左回転／右回転** で表示を90度ずつ回転します。回転は確認用の表示に適用し、元画像やLM Studioへの送信画像は変更しません。
- 購入日・店舗・税込合計・税額を上部にまとめました。支払方法・値引き・メモは **その他の情報** を開いて入力します。閉じても入力内容は保持します。
- 記録先と記録ボタンは画面下部に固定しています。記録先にマウスを重ねるとファイルの場所を確認できます。

## 税込合計と消費税額

- **合計金額（税込）** には、消費税と値引きを反映したレシートの最終合計を記録します。預り金・釣銭・税抜小計とは区別します。
- **うち消費税額** には、税込合計に含まれる消費税額を記録します。総税額が印字されず、税率別の税額がすべて読めた場合は、その税額だけを合算します。総税額と税率別内訳の不一致は確認メッセージを表示します。
- 税額は税込合計に再加算しません。不明な税額は空欄、明記された0円は0として扱います。不明な税額は元画像を確認して手入力できます。
- Excelの **支出一覧** の既存の「金額」列に税込合計、「税額」列に消費税額を保存します。**レシート別** でも「税込合計」「うち消費税額」を表示します。従来の家計簿・テンプレートを引き続き使えます。
- **レシート別** の商品一覧の下に **商品小計 → 消費税 → 合計（税込）** を表示します。商品金額がすべて入力済みで「商品小計＋税額＝税込合計」の場合は外税として表示し、この税額を金額不一致の警告から除きます。商品明細自体が税込合計に一致する場合は **うち消費税** と表示し、再加算しません。金額が一致しない場合は確認表示を残します。
- 以前の家計簿の表示も **家計簿・Excel → Excelを保存** で更新できます。消費税額が未記入の場合は、対象レシートの編集画面で入力してから保存してください。

## 画像一覧の絞り込み・まとめてチェック

- 一覧上部で **すべて／未読取／要確認／読取失敗／記録済み** を切り替えます。「要確認」は読み取り済みでExcelに未記録の画像です。読み取り中の画像は「すべて」で確認できます。
- 検索欄は **店舗名・画像ファイル名の部分一致** です。英字の大文字・小文字は区別しません。状態の絞り込みと併用できます。検索欄の×で検索を解除できます。
- **表示中をすべてチェック** は表示中の読み取り済み・記録済み画像にチェックを付けます。記録済み画像も個別にチェックでき、一覧からの削除に使えます。未読・読み取り中・処理待ち・読取失敗はチェック対象外です。日付や金額の検証は記録時に行うため、内容を確認してから記録してください。
- **チェックをすべて解除** は非表示の画像も含めて解除します。絞り込みや検索だけではチェックは解除されません。
- 件数欄には **選択5件（未記録2件・記録済み3件／非表示1件）** のように内訳を表示します。**未記録○件をExcelに記録** は、選択した未記録レシートだけを記録します。**選択○件を一覧から削除** は、記録済みを含む選択全件が対象です。どちらも非表示の選択を含みます。記録済み画像はチェックしても再記録しません。記録対象の非表示分は保存前の確認画面にも表示します。
- 条件を変更して編集中の画像が非表示になっても、右側の入力内容と画像は保持します。表示される案内で対象のファイル名を確認できます。
- 読み取り結果や編集中の店舗名の変更により条件から外れた場合、現在開いている画像は一時的に一覧に残し、その旨を表示します。別の画像を選ぶか、絞り込み・検索を変更すると通常の表示に戻ります。
- 検索条件・絞り込み・チェック状態も下書きと一緒に自動保存し、次回起動時に復元します。絞り込みは画像やExcelのデータを削除しません。
- **未読を一括読み込み／失敗分を再試行** は従来どおり、絞り込みに関係なく全画像の該当する状態が対象です。

## 取り込んだ画像を一覧から削除する

**レシート登録 → 一覧から削除…** で対象を選びます。

- **選択中の画像を削除**：現在開いている1件を削除します。絞り込みで一覧から隠れていても、開いている画像が対象です。
- **チェックした画像を削除**：チェック済みの画像をまとめて削除します。非表示のチェックも対象です。
- 記録済み画像を整理する場合は、**記録済み**で絞り込み、削除したい画像を個別にチェックするか**表示中をすべてチェック**を押し、**一覧から削除… → チェックした画像を削除**を選びます。
- **表示中の画像を削除**：現在の一覧に表示されている画像をまとめて削除します。未読・読取失敗・記録済みも対象です。例えば「記録済み」で絞り込んでから整理できます。

確認画面に件数・対象ファイル名・未記録件数・非表示件数を表示します。削除すると、対象画像の読み取り結果・入力途中の内容・チェックも一覧から取り除きます。**元の画像ファイル、Excelの記録、記録時に保存した画像は残ります。** 一覧下の **選択○件を一覧から削除** ボタンでも、チェックした画像を直接削除できます。

読み取り・接続処理中は削除できません。処理終了後に操作してください。削除結果はその場で保存し、再起動後も一覧から削除された状態を保ちます。下書きの保存に失敗した場合は削除せず、一覧と入力内容を保持します。

### 削除を元に戻す

- 一覧下の **削除を元に戻す（○件）** で、直前の削除をまとめて取り消せます。**直近10回の削除操作**を新しい順に戻せます。11回目以降は最も古い履歴から消去します。
- 読み取り結果・修正内容・チェック・記録済み状態・一覧の並び順を復元します。再起動後も利用でき、復元はその場で保存します。保存に失敗した場合は削除履歴を保持します。
- 復元時に別のレシートや手入力を編集していれば、その画面を保持します。入力欄が空の場合は、復元した画像を開きます。現在の絞り込みで非表示になる復元画像は、案内の件数で確認できます。
- 同じ画像を再度追加していた場合は、現在の編集を削除前の内容に置き換えるか確認します。「いいえ」で現在の編集と削除履歴を保持できます。
- 元画像が移動・削除されていても、保存してある文字情報は復元できます。元ファイル自体を復元する機能ではありません。
- 読み取り・接続処理中は取り消し操作を無効にします。**設定 → 下書きと画像一覧を消去** は削除履歴も消去します。旧版での削除や、履歴から消えた操作は元に戻せません。

## 作成済みのテンプレートに記録する

1. **家計簿・Excel → 保存先Excelを選ぶ**で、同梱の `templates/レシート家計簿_テンプレート.xlsx` または以前作成した家計簿を選びます。
2. 空のテンプレートを残したい場合は、**名前を付けて保存**で `2026年_家計簿.xlsx` などの名前を指定します。以後はそのファイルが記録先になります。
3. **レシート登録**で読み取り、記録先の表示を確認して、**この1件を記録**を押します。商品名・数量・単価・金額・補足を追記し、テンプレートのダッシュボードとレシート別表示を更新します。読み取った後に保存先を選んでも入力内容は保持されます。
4. **家計簿・Excel → Excelで表示**で確認できます。

テンプレートファイルを選ばず新規作成した家計簿も、同じ5シートのデザインになります。アプリ保存時に表示用シートを再生成するため、表示用シートの書式を手動で変更した場合はその変更が置き換わります。

## Excelファイルの保存・削除

| ボタン | 動作 |
| --- | --- |
| Excelを保存 | 登録済みの全レシートを現在のファイルへ保存し、集計と表示を更新。0件なら空の家計簿を作成 |
| 名前を付けて保存 | 登録済みの全レシートを別のファイルへ保存し、以後の記録先を切り替え。元ファイルは残る |
| 保存先Excelを選ぶ | このアプリの家計簿またはテンプレートを読み込み、追記先に設定 |
| Excelで表示 | 現在の家計簿をExcelなどの関連付けられたアプリで開く |
| Excelファイルを削除 | 確認後、現在の家計簿ファイルを削除して一覧を空にする。復元用バックアップを同じフォルダーへ保存 |

**Excelを保存**と**名前を付けて保存**の対象は登録済みのデータです。下書きの内容は、先に**この1件を記録**または**未記録○件をExcelに記録**で確定してください。一覧を月や検索で絞り込んでいても、全件を保存します。

削除したファイルは、**設定 → バックアップから復元**で `.before-delete-日時.xlsx` を選ぶと戻せます。削除後に再度保存・登録すると、同じ保存先に新しい家計簿が作られます。

## 家計簿の見方

- アプリの**家計簿・Excel**でレシートを選び、**選択したレシートの明細を見る**を押すと商品ごとの内容を表示します。一覧の行をダブルクリックしても開けます。
- Excelの**ダッシュボード**には累計、今月、月別・費目別の支出と最近のレシートを表示します。店舗名を押すと該当レシートに移動します。
- **レシート別**ではレシートごとに購入日、店舗、合計、支払方法、税額、値引き、メモ、商品名、個数、単価、金額、補足をまとめて表示します。
- **支出一覧**と**明細**は編集可能な元データです。**月別集計**は1行1か月で税込合計・件数・費目別内訳と支出推移グラフを表示します。記録期間内の支出がない月も0円で表示します。費目はレシート単位です。既存の家計簿はアプリで「Excelを保存」すると新表示へ更新されます。ダッシュボードとレシート別はアプリで保存したときに更新される表示用シートです。Excelで元データを直接編集した場合は、アプリで**再読み込み → Excelを保存**と操作すると表示用シートへ反映されます。

## よくある問題

- **更新しても画像一覧が残る**: 設定・下書き・一覧は `%LOCALAPPDATA%/ReceiptLedger` に自動保存します。実行ファイルの入れ替え後も復元されます。一覧を空にする場合は「設定 → 下書きと画像一覧を消去」を使います。未記録の内容と削除を戻す履歴も消えますが、Excelと元画像は残ります。

- **接続できない**: LM Studioのサーバー、LAN公開、IPアドレス、ポート、ファイアウォールを確認します。
- **認証できない**: LM Studioで発行したトークンを設定画面に入力し直します。
- **モデルが出ない**: LM Studioでローカル版モデルをダウンロード・読み込み、接続テストをやり直します。
- **画像を読めない**: 選択したモデルの画像入力対応を確認します。文字が小さい画像は、より鮮明な写真を使います。
- **読み取り結果を解釈できない**: 空欄の配列、円記号・桁区切り付き金額、JSON前後の思考タグやコード枠に対応しています。出力が途中で終わるなどの場合は1回だけ自動再試行します。再試行後も失敗すると、原因とモデルの終了理由を表示します。不完全なJSONを補って保存することはありません。
- **Qwen3.8 27Bで結果が空・遅い**: LM Studio側でモデルの「Enable Thinking」をオフ、または「Reasoning Effort」を low にして再試行します。レシート抽出には長い推論は不要です。
- **Excelに保存できない**: Excelで家計簿を開いている場合はいったん閉じてください。外部で編集した後は、家計簿タブで再読み込みしてください。

LAN内のHTTP通信は暗号化されません。信頼できる家庭内LANで利用してください。共有ネットワークで利用する場合は、HTTPSを提供する仕組みやVPNを追加してください。アプリはインターネット上のAPIに自動接続しません。

## 現在の対応範囲

JPEG、PNG、WebP、HEIC、HEIFの画像とドラッグ＆ドロップでの追加、レシート単位の費目分類、商品ごとの数量・単価・金額・補足、5シートのExcel保存、編集・削除、バックアップと復元に対応します。PDFやレシート内の複数費目への配賦は対象外です。LM Studioの実機モデルでの読み取り精度は、サンプルレシートを使って確認してください。

## 起動時の画像一覧と月別集計の表示

起動時は状態フィルターが「すべて」、検索欄が空欄になります。チェック状態と編集中の内容は復元します。月別集計では列を固定せず、見出し行を固定します。金額の「—」は0円で、欠損値ではありません。

## 同時解析数

**設定 → LM Studio サーバー → 同時解析数** で「1件（順番に解析）」または「2件（並列に解析）」を選びます。初期値は1件です。選択は自動保存され、次回起動時も保持されます。解析中に変更した場合は次の読み取りから適用します。

2件では、各レシートを別々のリクエストとして送信し、先に完了した画像から結果を表示します。完了した画像は残りの解析中でも編集できます。GPUメモリ使用量が増え、速度はサーバー設定・モデルによって異なります。エラーや速度低下がある場合は1件に戻してください。
