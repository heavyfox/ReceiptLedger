# 内部構成と検証方針

## 画面と処理の分担

| ファイル | 担当 |
|---|---|
| `main.py` | 起動と配布実行ファイルの自己テスト |
| `app.py` | MainWindow、操作の受け付け、一覧状態、編集、読み取りと記録の連携 |
| `receipt_panel.py` | レシート画面の部品・レイアウト・イベント接続 |
| `settings_panel.py` | 設定画面の部品・レイアウト・イベント接続 |
| `batch.py` | 下書き・一覧エントリー、最大2件の並列読み取り |
| `lm_client.py` | LM Studioとの通信、JSON解釈、自動再試行、原因コード |
| `image_io.py` / `image_viewer.py` | 画像変換と表示・拡大・回転 |
| `core.py` | レシートの検証、Excel読み書き、表示用シート生成 |
| `excel_validation.py` | 保存したExcelのXMLを独立に検査 |
| `diagnostics.py` | 記録項目を制限したログ、容量制限、診断情報のコピー用テキスト |
| `config.py` / `session_store.py` | 設定・資格情報と下書き保存 |
| `storage.py` / `data_backup.py` | 元画像の保存、世代管理、バックアップと復元 |
| `appearance.py` | Windows連動テーマ、配色、チェック表示 |

画面構築モジュールはMainWindowの部品属性とコールバックを使用します。処理の状態はMainWindowが保持します。既存の操作と信号接続を保って画面構築を分離した段階であり、画面ごとの状態管理までは分離していません。

## 読み取りから記録まで

1. 画像を一覧へ追加し、下書きの自動保存を開始します。
2. BatchReadWorkerが画像ごとにLMStudioClientを呼び出します。
3. モデル向け画像変換 → HTTP通信 → JSONの検証を実施します。不正・途切れた結果は1回だけ再試行します。
4. 完了した画像ごとに下書きを更新し、ユーザーが確認・修正します。
5. 記録操作で画像を保存し、Excelを一時ファイルへ書き出します。
6. 出力XMLの整合性を検証し、成功した場合だけバックアップとファイル置換を進めます。
7. 一覧の記録状態と下書きを更新します。

## 診断ログ

保存先は `%LOCALAPPDATA%/ReceiptLedger/logs/diagnostics.jsonl`。現在のファイルと3世代を保持し、各512KiB、合計最大約2MiBです。書き込み不能でもアプリの処理を中断しません。

イベント名と属性を許可リストで制限しています。日時（UTC）、処理時間、画像の拡張子、件数、同時解析数、HTTPステータス、結果と原因コード、一時的な処理IDのみ記録します。例外の本文、トレースバック、接続先、モデル名、認証情報、ファイル名・パス、画像データ、抽出したレシート本文は記録しません。

設定画面の「診断情報をコピー」は、アプリ・Python・OSの基本情報と、直近最大50件のイベントを取得します。ログ内容をコピー前にも検査し、未知の項目を除去します。診断情報の送信はユーザーが行います。ログは家計簿データの一括バックアップには含みません。

主な原因コード: `timeout`（通信時間切れ）、`network`（接続失敗）、`auth`（認証）、`http_error`（サーバー）、`image_decode`（画像変換）、`invalid_response`（応答JSON）、`invalid_receipt`（抽出形式）、`output_limit`（モデル出力上限）、`validation`（保存内容の検証）、`permission`（アクセス権）、`workbook_changed`（外部変更）。

## Excel出力の検証

Excelを起動せず、ZIP内のワークシート・描画・グラフXMLを読みます。openpyxlが保持する設定を再確認するだけでなく、実際に保存されたセル値・参照・表示設定を調べます。

- レシートIDと件数、税込合計、税額（0円と未記入を区別）。
- 月別・費目別合計、レシート件数、支出のない月、年の境界。
- 年ごとのグラフ、月名、金額の参照範囲、円のラベル、軸・目盛りの表示。
- 不一致時に既存ファイルを保持し、一時ファイルを片付けること。
- 1904年日付方式の既存ファイルと、利用者が追加したシートを保持すること。

`test_excel_validation.py` は、月名・軸・金額ラベル・税額を意図的に欠落させた出力も拒否することを検証します。`test_diagnostics.py` は、秘匿項目の除外、ログ容量、並列書き込み、コピー操作、通信と抽出の原因コードを確認します。既存テストでは画像対応、編集中の一括処理、一覧の操作、税の表示、バックアップ復元を引き続き確認します。

XMLの検証は各Excel閲覧ソフトの描画結果を保証するものではありません。文字の配置や見切れなどの見た目は、別途レビューが必要です。
