# ReceiptLedger v1.5.1

LM Studioでレシートを読み取り、確認・修正してExcel家計簿へ記録するWindowsアプリです。

## ダウンロード

通常の利用には **ReceiptLedger-v1.5.1-windows-x64.zip** を展開し、`ReceiptLedger/ReceiptLedger.exe` を起動してください。`_internal` フォルダも必要です。

Windows 10 / 11 x64向け（動作検証はWindows 11）。Python・Microsoft Excelのインストールは不要です。LM Studioと画像入力対応モデルは別途導入してください。画像は設定したローカルPCまたはLAN内のLM Studioへ送信します。

## 主な機能

- JPG/JPEG/PNG/WebP/HEIC/HEIFの取り込み・ドラッグ＆ドロップ・一括読み取り。
- 商品名・数量・単価・税込合計・税額の確認と修正、Excelへの一括記録。
- レシート別明細・ダッシュボード・月別集計。
- 下書き保存、検索・絞り込み、画像拡大・回転、一覧からの削除と取り消し。
- ライト／ダーク表示、バックアップ・復元、LM Studio接続設定の保存。

## v1.5.0からの変更

- 未読・読み取り失敗の画像にも、個別チェックと「表示中をすべてチェック」を使えるようにしました。
- チェックした未読・失敗の画像を一括で一覧から削除でき、削除の取り消しとチェック状態の復元にも対応します。
- Excelへの一括記録は読み取り済みの未記録画像が対象です。未読・失敗が選択されている場合は確認ダイアログで対象外の件数を表示します。
- 読み取り中・読み取り開始待ちの画像は、解析完了までチェックできません。読み取りなどの処理中は一覧からの削除を停止します。

## v1.4.2からv1.5.0までの変更

- 処理時間・画像形式・失敗原因を記録するローカル診断ログを追加しました。最大約2MBで自動整理します。
- 「設定 → 診断情報をコピー」で、不具合報告用の情報を取得できます。URL・認証情報・モデル名・画像・ファイル名・レシート本文は含みません。
- レシート画面と設定画面を専用モジュールへ分け、読み取り・編集・一括記録の操作を維持しています。
- Excel保存時、書き出したファイルの税込合計・税額・月別集計・グラフの月名・金額ラベル・軸表示を検証します。不一致がある場合は旧ファイルを上書きしません。
- 月またぎ・年またぎ・返金・税額0円／未記入、グラフの表示情報の欠落を検出する回帰テストを追加しました。

## 更新する方へ

アプリ内の「設定 → データ一式をバックアップ」を実行し、アプリを終了してから更新してください。実行ファイル横の `data` を使っている場合は、新版フォルダへ引き継ぎます。データ確認前に旧フォルダを削除しないでください。詳しくはリポジトリの `UPDATE.md` を参照してください。

保存先の仕様は従来と同じです。設定・下書き・画像一覧は `%LOCALAPPDATA%/ReceiptLedger` に保存されるため、実行ファイルを入れ替えても引き継がれます。
