# ReceiptLedger v1.4.1

LM Studioでレシートを読み取り、確認・修正してExcel家計簿へ記録するWindowsアプリです。

## ダウンロード

通常の利用には **ReceiptLedger-v1.4.1-windows-x64.zip** を展開し、`ReceiptLedger/ReceiptLedger.exe` を起動してください。`_internal` フォルダも必要です。

Windows 10 / 11 x64向け（動作検証はWindows 11）。Python・Microsoft Excelのインストールは不要です。LM Studioと画像入力対応モデルは別途導入してください。画像は設定したローカルPCまたはLAN内のLM Studioへ送信します。

## 主な機能

- JPG/JPEG/PNG/WebP/HEIC/HEIFの取り込み・ドラッグ＆ドロップ・一括読み取り。
- 商品名・数量・単価・税込合計・税額の確認と修正、Excelへの一括記録。
- レシート別明細・ダッシュボード・月別集計。
- 下書き保存、検索・絞り込み、画像拡大・回転、一覧からの削除と取り消し。
- ライト／ダーク表示、バックアップ・復元、LM Studio接続設定の保存。

## 前回公開版からの変更

- LM Studio サーバー設定に同時解析数（1件／2件）を追加。初期値は1件、変更は自動保存します。
- 2件ではレシートごとに独立したリクエストを送り、完了順に結果を表示します。
- 解析済みのレシートは並列解析中も編集できます。停止時は送信済みの処理を待ち、未送信分は未読のまま残します。

- 月別集計のグラフに金額ラベルと月名を追加し、年ごとにグラフを分けました。
- 月別集計の見出し・配色を改善し、D列とE列の固定境界線を解消しました。
- 起動時の画像一覧は「すべて」に統一しました。
- 税額未記入の確認ダイアログに対象画像名を表示します。

## 更新する方へ

アプリ内の「設定 → データ一式をバックアップ」を実行し、アプリを終了してから更新してください。実行ファイル横の `data` を使っている場合は、新版フォルダへ引き継ぎます。データ確認前に旧フォルダを削除しないでください。詳しくはリポジトリの `UPDATE.md` を参照してください。

保存先の仕様は従来と同じです。設定・下書き・画像一覧は `%LOCALAPPDATA%/ReceiptLedger` に保存されるため、実行ファイルを入れ替えても引き継がれます。
